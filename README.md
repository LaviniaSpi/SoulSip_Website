# SoulSip_Website
Meine Website ist einen Zusatz zu der Brand, welche wir in der 1-Tageschallenge erstellen sollten. Die Brand "SoulSip" handelt von einem modernen Cafe, welches deinen Drink in bezug zu deiner Persönlichkeit erstellt. 
Also wenn man eher eine sture, ehrgeizige und strukturierte Persönlichkeit hat, wäre ein Midnight Tonic oder ein schwarzer Kaffe die perfekte Wahl.
Um der Person den richtigen Drink zuweisen zu können, wird ein Test ausgefüllt. In diesem Test kommen alltägliche Fragen ins Spiel zum Beispiel, was man am Samstagmorgen am liebsten macht oder welches Wetter man am liebsten mag.

Bei Erstellen des HTML Codes hatte ich keine Schwierigkeiten, da ich genau wusste, welchen Inahlt ich in meiner Website haben wollte. Der CSS-Code ist mir jedoch sehr schwer gefallen, da ich mich wieder von neuem in das Konzept einarbeiten musste und mich nicht an vieles aus dem ÜK erinnern konnte. Da ich aber die Hilfsblätter noch hatte habe ich mich viel an diesem Orientiert oder teilweise auch ChatGPT gefragt wie etwas funktioniert und selbst eingefügt.
Durch das Projekt habe ich sicher meine CSS Kentnisse wieder auffrischen können und ein neues Tool zum speichern kennengelernt.

# Funktionen
- man kann einen kurzen Test machen
- die Drinks sind mit einer kurzen Bespreibung aufgeführt
- es gibt eine Anleitung wie dieses Cafe funktioniert

# Technologien
- HTML5
- CSS3
- JavaScript

# Nutzung
Öffne index.html in deinem Browser
